## Build & Test Commands

- Build: `cargo build`
- Run: `cargo run`
- Test all: `cargo test`
- Test single: `cargo test <test_name>`
- Lint: `cargo clippy`
- Format: `cargo fmt`
- Format check: `cargo fmt -- --check`
